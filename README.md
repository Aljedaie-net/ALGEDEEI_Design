# ALGEDEEI Design (تصاميم الجديعي)

منصة سوق التصاميم حسب الطلب (Design-on-Demand Marketplace Platform) الخاصة بمشروع تصاميم الجديعي.

## عن المشروع
يهدف المستودع إلى توثيق وبناء منصة سوق إلكتروني يربط بين العملاء والمصممين، مع نظام مالكي متكامل يحفظ عمولة المنصة بشكل مخفي عن المصممين، ومحافظ رصيد وسحب، واستقبال طلبات عبر الموقع وتطبيق واتساب المرتبط بالموقع.

## خطة البناء التفصيلية (Build Plan)
تم إعداد دليل كامل لخطة العمل وخطة المطوّر (A to Z) للاستخدام مع المولدات البرمجية أو التطوير المباشر.
راجع الملف:
[`BUILD_PLAN.md`](./BUILD_PLAN.md)

### أهم محتويات خطة البناء:
1. **الفكرة والأهداف:** منصة تصميم عربية بالكامل بدعم RTL.
2. **الأدوار والصلاحيات:** عميل، مصمم، مدير النظام (Admin).
3. **دورة حياة الطلب والحالات:** من المسودة والدفع حتى التسليم والسحب.
4. **النظام المالي المحكم:** سجل مالي غير قابل للتعديل (Immutable Ledger)، حظر الأرصدة السالبة، وإخفاء عمولة المنصة وسعر العميل عن المصمم.
5. **جداول قاعدة البيانات:** هيكلية كاملة لـ `users`, `orders`, `wallets`, `ledger`, `services` وغيرها.
6. **ربط واتساب التجاري (WhatsApp Cloud API):** استقبال الطلبات والتنبيهات التلقائية.
7. **المطالبات والجاهزية (Prompts Stage-by-Stage):** برومبتات جاهزة لكل مرحلة من المراحل 0 إلى 7.
